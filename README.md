# Rubina Pokhrel Portfolio

Next.js (App Router) and Tailwind CSS v4. Edit all text in `src/data/site.ts`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

SEO: metadata, Open Graph, JSON-LD (Person, WebSite), `sitemap.xml` and `robots.txt` are set in `src/app/layout.tsx`, `sitemap.ts` and `robots.ts`.
